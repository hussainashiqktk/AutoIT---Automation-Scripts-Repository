# 🔧 Automation Scripts Repository

This repo contains all of my personal and SOC-related automation scripts, primarily built with **AutoIt**. It includes tools for productivity, threat intel, file organization, and general system enhancements.

## 📂 Categories

### 📁 sorter/
File organization tools:
- `sorter_by_extension.au3` – Sorts files by file extension dynamically.
- `sorter_by_category.au3` – Categorizes files into Documents, Videos, Images, etc.

### 📁 soc/
SOC analyst tools:
- `soc_toolkit_launcher.au3` – Opens SIEM + threat intel + notepad.
- `ioc_clipboard_monitor.au3` – Detects copied IOCs (IP/Hash) and opens them in VT/AbuseIPDB.

### 📁 productivity/
Everyday boosts:
- `daily_notes_launcher.au3` – Opens Notepad with a timestamped template.
- `open_work_sites.au3` – Opens your most-used tabs.

### 📁 utils/
Helpers and sub-functions:
- `path_resolver.au3` – Auto-detects Chrome or other app paths.
- `chrome_checker.au3` – Ensures Chrome is installed before launch.

---

## 🔧 How to Run

1. Install [AutoIt](https://www.autoitscript.com/site/autoit/downloads/)
2. Open `.au3` files in SciTE editor
3. Hit **F5** to run, or compile to `.exe` for standalone use
